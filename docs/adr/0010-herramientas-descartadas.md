# ADR-0010: Herramientas descartadas

Estado: aceptada · Fecha: 2026-09-26

## Contexto
Se evaluaron herramientas adicionales para el portfolio.

## Decisión
Descartadas: OWASP ZAP, herramientas de carga (k6, JMeter), Pact, pgTAP y TypeScript en código de producto (TS solo en Playwright).

## Consecuencias
El alcance se mantiene en pruebas funcionales, de contrato, integración y E2E. Se puede reabrir con un ADR nuevo si cambia el objetivo.
