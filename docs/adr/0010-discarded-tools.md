# ADR-0010: Discarded tools

Status: Accepted · Date: 2026-09-26

## Context
Additional tools were evaluated for the portfolio.

## Decision
Discarded: OWASP ZAP, load testing tools (k6, JMeter), Pact, pgTAP and TypeScript in product code (TS only in Playwright).

## Consequences
The scope stays on functional, contract, integration and E2E testing. It can be reopened with a new ADR if the goal changes.
